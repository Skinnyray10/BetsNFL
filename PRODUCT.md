# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

SvelteKit 3.0 + Svelte 5 (runes mode) + TypeScript 6 + Tailwind CSS 4.3. Monorepo architecture with separate API (Node.js + Hono) and web app. Build with Vite 8.

## Users

**Primary users:** Apostadores recreacionales (recreational bettors) and NFL fans who want data-driven insights for entertainment and occasional wagering.

**Situation:** Users visit during the NFL week (Wednesday through Sunday) to:
- Research upcoming games before placing bets
- Compare teams and matchups for weekend picks
- Follow predictions and see how analysis plays out
- Engage with NFL content between games

**Job to be done:** Make more informed betting decisions with clear analysis while managing risk responsibly, and stay engaged with NFL analysis during the week.

## Product Purpose

An NFL prediction platform that uses AI (Groq LLM) to analyze matchups and provide clear betting insights with integrated bankroll management, making sports analysis accessible to recreational bettors and fans.

Success means users feel confident in their understanding of games, manage their betting budget responsibly, and stay engaged with NFL analysis throughout the week.

## Positioning

**The unique mechanism:** Integrated bankroll management that automatically calculates recommended stake sizes, minimum acceptable odds, and betting edge—built into every prediction, not as an afterthought.

Unlike static odds aggregators or pure prediction sites, this combines AI-powered analysis with financial guardrails that help users bet responsibly based on confidence levels and probability calculations.

## Operating Context

**When users arrive:**
- Mid-week (Wednesday-Thursday): Early research, comparing multiple games
- Friday-Saturday: Final decision-making before weekend games
- Sunday: Live checking of predictions vs. actual games
- Post-game: Reviewing analysis accuracy

**Usage patterns:**
- Quick scans: 2-5 minutes to check top picks
- Deep dives: 10-15 minutes comparing teams and reading analysis
- Pre-bet verification: Confirming stake and odds before placing wagers

**Environment:**
- Mobile and desktop (responsive required)
- Often used alongside sportsbook apps or websites
- May be referenced during live games

## Capabilities and Constraints

**Data sources:**
- Live game data and team stats from ESPN public API (no key required)
- AI predictions generated by Groq (openai/gpt-oss-120b model)
- Real-time scores, rosters, and team information

**Technical capabilities:**
- Predictions with confidence scores (0-100%), win probabilities, and score forecasts
- Automatic bankroll calculations: stake (1-10 scale), minimum odds, expected value
- Server-side prediction caching (15-minute TTL)
- Fallback prediction system when LLM unavailable
- Responsible gambling warnings on all prediction views

**Hard constraints:**
- All API keys (Groq, future services) must remain server-side only
- Never expose prediction algorithms or prompt engineering to client
- Legal disclaimers required on all betting-related content
- No guaranteed results or win-rate claims without historical data

**Open decisions:**
- Whether to track historical prediction accuracy
- How far back to show past games (currently only current week)
- Social features (sharing picks, following other users)

## Product Principles

1. **Clarity over complexity:**
   Present AI analysis in plain language. Probability bars beat jargon. "56% chance to win" is clearer than "implied odds of 1.79."

2. **Trust through transparency:**
   Show confidence scores, key factors influencing predictions, and model limitations. Never hide uncertainty.

3. **Responsible gambling first:**
   Bankroll management isn't optional—it's built into every prediction. Stake recommendations prevent users from overextending.

4. **Speed matters:**
   Cached predictions, optimized data loading, instant filtering. Users shouldn't wait for insights.

5. **Data-driven decisions, not gut feelings:**
   Visualize probabilities, trends, and comparisons. Help users see the numbers, not just read analysis.

## Accessibility & Inclusion

**Minimum standard:** WCAG 2.1 Level AA compliance
- Sufficient color contrast for all text (minimum 4.5:1 for body, 3:1 for large text)
- Keyboard navigation for all interactive elements
- Focus indicators on all clickable/tappable areas

**Specific requirements:**
- Screen reader friendly for critical data: scores, probabilities, stake recommendations
- Probability bars include text labels (not color-only encoding)
- Disclaimers and warnings must be perceivable by all users
- Responsive design supports zoom up to 200% without breaking layout

**Future considerations:**
- Spanish language support (large demographic in sports betting)
- High-contrast mode toggle for visibility in bright outdoor settings
- Text size preferences for older users
